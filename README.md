# WOO Chat — Landing Page

Marketing website for **WOO Chat** by Esowolf — a WhatsApp Business API SaaS platform.

Live: https://woochatofficial.esowolf.in

## Pages
- `index.html` — single-page site (Hero, Features, How it works, Pricing, Contact)
- `privacy.html`, `terms.html`, `refund.html` — legal pages
- `og-image.png`, `favicon.ico`, `favicon.png` — branding
- `robots.txt`, `sitemap.xml` — SEO

Static HTML/CSS/JS. Dark theme, brand colours black + orange (#FC8706).
